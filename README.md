# Ecommerce-Data-Analysis

E-Commerce Sales Data Analysis & Dashboard
📌 Project Overview
This repository presents an end-to-end data analysis project on an E-Commerce sales dataset. The project demonstrates the full data lifecycle: taking raw, unstructured sales data, cleaning and transforming it, conducting analytical queries in SQL, and visualizing key business metrics through an interactive Power BI dashboard.
🛠️ Tech Stack & Tools Used
Data Cleaning & Transformation: Excel / Python (Pandas)

Database & Querying: SQL (Data Extraction, Aggregations, Window Functions)

Data Visualization: Power BI (Interactive Dashboard & KPI Tracking)

Documentation & Web Report: HTML / Markdown

🔍 Key Project Steps
Data Cleaning & Preprocessing

Handled missing values, duplicates, and inconsistent data types from the raw dataset (Ecommerce_Unclean_Project - Copy.xlsx).

Standardized column names, formatted dates, and exported the cleaned output to Clean_Ecommerce.csv / Clean_Ecommerce.xlsx.

SQL Analysis (Ecommerce Sql_queries.sql)

Calculated key metrics such as total revenue, average order value (AOV), and overall sales volume.

Segmented sales performance by product category, customer demographic, and geographic region.

Executed time-series queries to identify monthly trends, peak sales periods, and seasonality patterns.

Power BI Dashboard (Ecommerce_dashboard_PowerBI.pbix)

Built interactive visual reports featuring high-level KPIs, sales breakdown charts, category filters, and regional slicers.

Enabled dynamic data exploration to track performance across different timeframes and product segments.
