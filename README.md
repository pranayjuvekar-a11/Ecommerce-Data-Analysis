# Ecommerce-Data-Analysis

E-Commerce Sales Data Analysis & Dashboard

📌 Project Overview

This repository presents an end-to-end data analysis project on an E-Commerce sales dataset. The project demonstrates the full data lifecycle: taking raw, unstructured sales data, cleaning and transforming it, conducting analytical queries in SQL, and visualizing key business metrics through an interactive Power BI dashboard.

🛠️ Tech Stack & Tools Used

1.Data Cleaning & Transformation: Excel / Python (Pandas)

2.Database & Querying: SQL (Data Extraction, Aggregations, Window Functions)

3.Data Visualization: Power BI (Interactive Dashboard & KPI Tracking)

4.Documentation & Web Report: HTML / Markdown

🔍 Key Project Steps

1.Data Cleaning & Preprocessing

i.Handled missing values, duplicates, and inconsistent data types from the raw dataset (Ecommerce_Unclean_Project - Copy.xlsx).

ii.Standardized column names, formatted dates, and exported the cleaned output to Clean_Ecommerce.csv / Clean_Ecommerce.xlsx.

2.SQL Analysis (Ecommerce Sql_queries.sql)

i.Calculated key metrics such as total revenue, average order value (AOV), and overall sales volume.

ii.Segmented sales performance by product category, customer demographic, and geographic region.

iii.Executed time-series queries to identify monthly trends, peak sales periods, and seasonality patterns.

3.Power BI Dashboard (Ecommerce_dashboard_PowerBI.pbix)

i.Built interactive visual reports featuring high-level KPIs, sales breakdown charts, category filters, and regional slicers.

ii.Enabled dynamic data exploration to track performance across different timeframes and product segments.

📈 Key Insights & Business Value

Revenue Drivers & Customer Behavior: Identifies top-performing product categories and quantifies Average Order Value (AOV) to highlight core profit centers.
Trend & Seasonality Identification: Time-series SQL queries pin-point peak buying windows, allowing for optimized inventory management and targeted marketing campaigns.
Regional Performance Tracking: Geographic breakdown visuals highlight high-value territory segments to guide regional sales strategies.
Interactive Decision-Making: The Power BI dashboard replaces static reports with dynamic filters, enabling stakeholders to drill down into custom date ranges, regions, and categories effortlessly.
